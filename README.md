# Inteligencia Artificial - IUA

Repositorio personal de la materia **Inteligencia Artificial** del **Instituto Universitario Aeronáutico (IUA)**.

En este repositorio voy desarrollando y organizando las actividades prácticas solicitadas por el profesor a lo largo de la materia. El objetivo es dejar documentado el proceso de aprendizaje, los análisis realizados y los recursos utilizados en cada trabajo.

## Contenido

- `Actividades/`: notebooks y trabajos prácticos de la materia.
- `Datasets/`: conjuntos de datos utilizados en las actividades.

## Actividades

Actualmente, el repositorio incluye:

- `Actividad_02/Actividad_02.ipynb`: análisis exploratorio de datos sobre jugadores y equipos. Incluye revisión de tipos de variables, estadística descriptiva, análisis de relaciones y visualizaciones.

## Tecnologías y herramientas

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Cómo utilizar el repositorio

1. Clonar o descargar este repositorio.
2. Abrir la carpeta desde Jupyter Notebook, JupyterLab o Visual Studio Code.
3. Ejecutar las celdas de las notebooks en orden.
4. Verificar que las rutas relativas a los datasets coincidan con la estructura del repositorio.

## Propósito

Este repositorio tiene un propósito académico y funciona como registro de las actividades realizadas durante la cursada. Los contenidos pueden ampliarse a medida que avance la materia.
